Privacy and access

Inventory records are isolated between application users. Armory Ledger does not intentionally expose one user's inventory to another ordinary application user.

The Armory Admin role provides account-administration identity information, shared reference-data views, and announcement management. It does not grant access to another user's inventory or inventory-derived summaries.

Manufacturer and caliber names are shared reference data available to users of this installation. Adding a reference name does not share the inventory record that uses it.

Because Armory Ledger is self-hosted, the operator or administrator of this installation may have infrastructure-level access to the database, host, backups, logs, or related systems. Application access controls do not prevent that infrastructure access.

Authentication is handled by the identity provider configured for this installation. Infrastructure, identity providers, and any configured support services are operated separately from the upstream software project.
